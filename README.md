# MOG BATTLE — Telegram-бот

Бот для баттлов в стиле присланного скрина: игрок кидает открытый вызов
("Бросить вызов"), пересылает карточку в чаты — первый, кто нажмёт
«Принять вызов», сражается с ним. Победитель определяется случайно, но
с учётом рейтинга (чем выше рейтинг — тем выше шанс выиграть), рейтинг
обеих сторон после этого меняется (Elo-подобная формула).

## Возможности

- `/start` — регистрация, приветствие (текст + фото, настраиваются админом), главное меню.
- ⚔️ **Бросить вызов** — создаёт карточку-баттл (как на примере) с фото профиля и рейтингом,
  кнопка «Принять вызов» под ней. Карточку можно переслать в любые чаты стандартной функцией
  Telegram «Переслать».
- Когда кто-то нажимает «Принять вызов» — бот определяет победителя, обновляет рейтинг
  обоих и присылает **детальную карточку результата**: разбивка по категориям (Аватар,
  @username, О себе, Подарки, Стоимость, Регистрация, Уровень TG) с полосками и очками,
  корона у победителя, штамп "MOGGED" у проигравшего (см. `scoring.py` и `images_result.py`).

  Все категории считаются по **настоящим данным Telegram**, без случайных чисел
  (Bot API 10.0, `python-telegram-bot` 22.8): количество фото профиля, юзернейм, био,
  подарки из профиля (`getUserGifts`: сколько всего, сколько NFT, сумма цен обычных
  подарков в звёздах), официальный уровень аккаунта Telegram и Premium. Если человек
  скрыл уровень или подарки настройками приватности — бот честно пишет «скрыт» / «нет».
  Единственное приближение — «Регистрация»: Telegram никому не отдаёт дату создания
  аккаунта, поэтому она оценивается по ID (помечена знаком ≈).
- 🔁 **Реванш** — кнопка под карточкой результата. Нажать её может любой из двух участников:
  карточка превращается в запрос реванша с кнопкой «⚔️ Принять реванш», которую может нажать
  **только соперник** (остальным бот ответит, что вызов адресован другому игроку). Сопернику
  дополнительно приходит напоминание в личку. На один баттл — один реванш, после реванша
  можно запросить следующий.
- 👤 **Мой профиль** / `/me` — рейтинг (LTN), место в рейтинге, победы/поражения, плюс
  кастомизация: можно задать свой статус (влияет на категорию «О себе» на карточке
  результата) и выбрать дизайн карточки вызова — ⚡ Neon (по умолчанию) или ⚪ Classic.
  В профиле показывается блок «📊 Статистика Telegram» — те же реальные категории и баллы,
  что на карточке результата.
- `/profile` — профиль любого игрока: `/profile @username`, `/profile 123456789` или ответом
  на сообщение человека в чате. Просто `/profile` — свой профиль. Смотреть можно тех, кто
  уже запускал бота.
- 🏆 **Рейтинг** / `/top` — топ-10 игроков.
- 🔒 **Приватность** / `/privacy` — честно объясняет пользователю, какие данные о нём
  бот реально хранит и использует, а что является игровой (нереальной) метрикой.
- `/admin` — панель администратора (доступна ID **8717087613** и **8320905919**; список
  админов — `ADMIN_IDS` в `config.py`):
  - изменить текст приветствия и/или фото приветствия. Оформление сохраняется (жирный,
    цитаты, эмодзи), а `<ник>` (или `{ник}`) в тексте заменяется на имя человека.
    `/clear_photo` — убрать фото приветствия;
  - написать сообщение от имени бота всем пользователям (рассылка);
  - посмотреть статистику (сколько человек запустило бота), полный рейтинг и
    отдельный список **всех** пользователей с их Telegram ID (вкладка «👥 Пользователи»);
  - забанить / разбанить пользователя по Telegram ID;
  - разослать конкретный баттл (по его ID, указан в подписи карточки) всем
    пользователям бота — отдельная функция помимо ручного пересылания сообщений;
  - включить/выключить **обязательную подписку** на канал или чат (см. ниже).

## Вызовы в любых чатах и группах

- **`@mogggbattle_robot`** в поле ввода любого чата → «⚔️ Бросить вызов». Кто первый нажмёт
  «Принять вызов», тот и соперник. **`@mogggbattle_robot @ник`** → вызов, который может
  принять только этот человек. Нужен включённый inline-режим (см. ниже). Бросать вызовы так
  может только тот, кто хоть раз запускал бота (иначе бот предложит его запустить).
- В группе, где есть бот:
  - `мог` (или `.мог`, `!мог`, `/mog`) — открытый вызов в чат;
  - `мог @ник` — вызов конкретному человеку;
  - `мог` **ответом на сообщение** — баттл с автором сообщения сразу, без ожидания.
- `/top` показывает **топ недели** (победы за последние 7 дней) и общий рейтинг.

⚠️ **Чтобы бот слышал слово «мог» в группах**, выключи у него режим приватности:
**@BotFather → /mybots → бот → Bot Settings → Group Privacy → Turn off**, затем удали бота
из группы и добавь заново (иначе настройка не применится к этой группе). Либо просто сделай
бота администратором группы. Команда `/mog` работает и без этого.

## Обязательная подписка на канал

В админ-панели есть кнопка **«📢 Обязательная подписка»**. После её нажатия пришли
юзернейм канала (например `@mychannel`) или его числовой ID.

⚠️ **Важно:** бот должен быть добавлен в этот канал/чат **как администратор** —
без этого Telegram не даёт боту проверять, кто подписан, и функция не будет работать
(если бот не сможет получить доступ к каналу, ты увидишь ошибку сразу при настройке).

Как это работает для игроков: как только подписка включена, при любой попытке
использовать бота (даже `/start`) человеку без подписки показывается сообщение
«Подпишись на канал» с двумя кнопками — «Перейти в канал» и «✅ Я подписался».
Пока он не подпишется и не нажмёт эту кнопку, ни одна функция бота ему не доступна
(кроме `/privacy` — она остаётся открытой всегда, чтобы человек в любом случае мог
узнать, что бот про него хранит).

Чтобы отключить обязательную подписку — снова нажми ту же кнопку в админ-панели и
пришли слово `off`.

## Важно: включи inline-режим у бота (один раз)

Обычная пересылка сообщений в Telegram **всегда стирает кнопки** — это ограничение
самого Telegram, а не бота. Поэтому вместо "Переслать" в карточке вызова есть кнопка
**«📤 Отправить в чат / другу»** — она открывает список чатов и отправляет карточку уже
готовым сообщением от имени бота, кнопка «Принять вызов» при этом сохраняется.

Чтобы это заработало, один раз включи inline-режим у бота через @BotFather:
1. Напиши **@BotFather** → `/mybots` → выбери своего бота.
2. **Bot Settings → Inline Mode → Turn on**.
3. На вопрос про placeholder-текст можно ответить, например, "Отправить вызов".

Без этого шага кнопка «📤 Отправить в чат / другу» будет открывать пустой список.

## Деплой на Amvera (хостинг)

Файл `amvera.yaml` уже лежит в проекте — конфигурация для Amvera готова, ничего писать
вручную не нужно.

1. Зарегистрируйся на **amvera.ru**.
2. **Создать проект → тип "Приложение"**. Можно сразу выбрать окружение Python (версию
   можно не трогать — используется 3.11 из `amvera.yaml`).
3. Залей файлы проекта (кнопка загрузки через интерфейс — можно перетащить всю папку
   `mogbattle_bot`, Git не обязателен). **Не загружай** папку `data/` — на сервере база
   создастся автоматически в постоянном хранилище.
4. В разделе **«Конфигурация»** проверь, что `amvera.yaml` подхватился (requirements —
   `requirements.txt`, точка входа — `bot.py`, постоянное хранилище — `/data`).
5. В разделе **«Переменные и секреты»** добавь:
   - `BOT_TOKEN` — токен бота (тот же, что в `config.py`; так секретнее — токен не будет
     лежать в открытом виде в репозитории)
   - `DB_PATH` = `/data/mogbattle.db` — база будет жить в постоянном хранилище и не
     потеряется при обновлениях
   - `PYTHONUNBUFFERED` = `1` — чтобы логи бота (print) были видны в панели Amvera сразу,
     а не с задержкой
6. Нажми **«Собрать»** (или сделай `git push`, если решишь работать через Git). Следи за
   статусом — сначала «Выполняется сборка», затем «Успешно развёрнуто».
7. Проверь логи приложения в панели — там должна появиться строка `MOG BATTLE bot started`.

Если бот не запускается — почти всегда причина в `requirements.txt` (опечатка в названии
пакета) или в неверном пути к `bot.py`. В логах сборки будет видно, что именно пошло не так.

## Установка и запуск (локально, на своём ПК)

1. Убедись, что стоит Python 3.10+.
2. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Токен бота и твой admin ID уже прописаны в `config.py`. Если хочешь не хранить токен
   в коде — можно вместо этого задать переменную окружения `BOT_TOKEN` (см. `config.py`,
   она уже это поддерживает).
4. Запусти бота:
   ```bash
   python3 bot.py
   ```
   База данных SQLite создастся автоматически в `data/mogbattle.db`.
5. Чтобы бот работал постоянно на сервере — заверни его в `systemd`-сервис, `screen`/`tmux`
   сессию или Docker-контейнер (по желанию могу собрать и это).

## Важно про безопасность токена

Ты прислал токен бота прямо в чат — если переписка может быть где-то видна посторонним,
на всякий случай зайди к **@BotFather → /mybots → выбери бота → API Token → Revoke**,
сгенерируй новый и просто замени значение `BOT_TOKEN` в `config.py`. Остальной код
менять не придётся.

```
mogbattle_bot/

├── config.py         — токен, ID админа, настройки рейтинга
├── db.py             — вся работа с SQLite (пользователи, баттлы, настройки)
├── images.py         — генерация картинок карточек (Pillow)
├── keyboards.py      — inline/reply-клавиатуры
├── handlers/
│   ├── start.py       — /start и приветствие
│   ├── battle.py      — создание вызова и обработка «Принять вызов»
│   ├── profile.py      — профиль и рейтинг
│   ├── admin.py        — вся админ-панель
│   └── common.py       — общие хелперы (аватарки и т.п.)

```
